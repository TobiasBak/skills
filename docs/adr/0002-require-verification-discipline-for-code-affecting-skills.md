# Require Verification Discipline for Code-Affecting Skills

Code-Affecting Skills must reflect Verification Discipline and Behavioral Coverage when their workflow reaches implementation. They should prefer black-box behavior checks through a useful Verification Surface, treat weak verification surfaces as problems to improve, and clearly state verification gaps when only partial checks are possible. This costs more upfront than shallow unit tests or compilation-only checks, but prevents skills from creating false confidence in code, UI, scripts, and generated artifacts.
